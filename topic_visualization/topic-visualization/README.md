# Project 01 - Political Posters

## About

This project looks at political posters from the Smithsonian Institution collection.

The visualization focuses on posters that are tagged with the topic "Politics" and shows the other topics connected to them.

## Data

The data comes from the Smithsonian Institution Open Access API.

I used the topic information in the poster metadata to find political posters and count the topics connected to them.

## Visualization

"Politics" is placed in the center, with related topics arranged around it.

The size of each topic shows how often it appears in the political posters.

The poster images are shown on the right side.

When you hover over a topic, the related posters are highlighted.

## Process

I first explored the Smithsonian API and looked at the metadata for political posters.

I filtered the data to posters that included "Politics" and then counted the other topics connected to those posters.

I used D3.js to create the topic layout and connect the topics to "Politics."
